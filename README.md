# Функциональные стили речи — викторина

Интерактивная командная викторина для открытого урока.
Русский язык · 1 курс · стоматология · уровень A2 · подсказки на узбекском (латиница).

Игра идёт на одном экране (проектор). Команды отвечают устно с мест,
преподаватель отмечает, кто ответил верно. База данных не нужна — счёт
сохраняется в браузере и не пропадает при перезагрузке страницы.

## Ход игры

1. **Настройка** — 2–4 команды, названия, таймер (выкл / 20 / 30 / 45 с).
2. **Теория** — 5 стилей: где используются и главные признаки.
3. **Раунд 1 «Какой стиль?»** — 10 текстов, +1 балл.
4. **Раунд 2 «Найди лишнее»** — 5 заданий, +1 балл.
5. **Раунд 3 «Скажи иначе»** — 5 заданий, +2 балла.
6. **Итоги** — пьедестал.

## Управление (для преподавателя)

| Действие | Мышь | Клавиша |
|---|---|---|
| Показать ответ / дальше | кнопка справа внизу | `→` `Пробел` `Enter` |
| Назад | кнопка слева внизу | `←` |
| Отметить ответ команды | нажать на вариант | — |
| Начислить балл команде | нажать на команду внизу | `1` `2` `3` `4` |
| Подсказка на узбекском | кнопка `UZ` | `H` |
| Пауза таймера | нажать на таймер | — |
| Полный экран | кнопка справа вверху | `F` |

Работает и с пультом-кликером для презентаций (`PageUp` / `PageDown`).
Повторное нажатие на команду снимает балл.

## Как изменить вопросы

Все тексты лежат в `src/data/rounds.ts`, описания стилей — в `src/data/styles.ts`.

## Запуск

```bash
npm install
npm run dev
```

## Деплой на Vercel

Залить репозиторий на GitHub → в Vercel «Add New Project» → выбрать репозиторий.
Vercel сам определит Vite; настройки по умолчанию подходят
(Build: `npm run build`, Output: `dist`).
